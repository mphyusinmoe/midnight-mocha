# ☕ Midnight Mocha

A responsive web application project developed using HTML5, CSS3, JavaScript, and custom styling frameworks.

## 🚀 Key Features
- **Interactive UI**: Custom component layouts powered by JavaScript (`fooditem.js`).
- **Responsive Layout**: Integration with Bootstrap and Owl Carousel for seamless viewing across devices.
- **Iconography & Styling**: Uses FontAwesome for vector icons and clean, dedicated stylesheets.
- **Project Documentation**: Includes project reports and assets organized under the repository folder structure.

## 🛠️ Built With
- **HTML5** & **CSS3**
- **JavaScript (ES6)**
- **Bootstrap**
- **Owl Carousel**
- **FontAwesome**
